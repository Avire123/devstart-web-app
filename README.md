# DevStart: Beginner Web Developer Hub

DevStart is a single-file interactive web application designed to help beginner web developers practice coding, look up syntax, test their knowledge, and manage project ideas.

## Features
- **Code Sandbox:** Live HTML/CSS/JS editor with dynamic preview.
- **Cheat Sheet:** Searchable reference cards for core web concepts.
- **Interactive Quiz:** Test core web development knowledge.
- **Ideas Generator:** Project ideas with step-by-step guidance.
- **Scratchpad:** LocalStorage-backed developer note-taking tool.
